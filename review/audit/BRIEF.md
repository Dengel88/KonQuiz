# Аудит вопросов КонКвиза — задание для агента-проверяльщика

## Контекст игры
КонКвиз — викторина-стратегия в Telegram (3 игрока, карта России, бои за земли). Аудитория —
обычные русскоязычные пользователи Telegram, не эрудиты-профи. Два типа вопросов:
- **CHOICE** — 4 варианта, 10 секунд на ответ, решает исход боя. Должен читаться за 3–4 секунды.
- **EXACT** — ответ числом на цифровой клавиатуре (только неотрицательные целые, без минуса и
  запятой), побеждает ближайший. `is_year=true` — ответ это год.
Сложность: 1 — знает большинство, 2 — средний эрудит, 3 — знатоки.
Поле `fact` скрыто во время вопроса и показывается ПОСЛЕ ответа как «интересный факт».

## Твоя задача
Проверить КАЖДЫЙ вопрос из своего входного файла `review/audit/input_<часть>.json` и записать
отчёт в `review/audit/report_<часть>.md`. **Файлы в `app/questions/` НЕ редактировать.**

Для каждого вопроса проверь:
1. **Достоверность.** Правильный ответ верен; ни один «неправильный» вариант не верен тоже
   (частичная правота, спорные трактовки, «формально тоже да»); факт без неточностей.
   Для EXACT — точное число и нет ли расхождений между авторитетными источниками (высоты гор,
   длины рек, даты по старому/новому стилю — частые ловушки). Если источники расходятся —
   это проблема вопроса: ответ «ближайший» должен быть однозначным.
2. **Устойчивость.** Не устареет ли ответ (рекорды, «самый большой/новый», население,
   действующие лица). Для Крипты и ИИ — никаких курсов, капитализаций, «последних моделей».
3. **Формулировка.** Однозначна, коротка, не подсказывает ответ; варианты одного типа и
   правдоподобны (нет «шуточного» лишнего варианта); факт не дублирует вопрос.
4. **Интересность 1–5.** 1 — школьная скука/зубрёжка дат, 5 — «ого, не знал», хочется
   переслать другу. Хороший вопрос — тот, где можно догадаться рассуждением.
5. **Сложность.** Соответствует ли указанная сложность реальной (предложи свою).
6. **Безопасность для продукта.** Политически острое, современная политика, религиозные
   споры, трагедии как развлечение, спорные территории — пометь RISK.

Проверяй через веб-поиск (WebSearch / WebFetch) всё, в чём нет абсолютной уверенности, и ВСЕ
числа в EXACT. Предпочитай авторитетные источники (энциклопедии, официальные сайты, научные
публикации); Википедию можно, но для спорных чисел сверяй со вторым источником.
Не трать поиск на очевидное («Кто основал Санкт-Петербург?»).

## Формат отчёта `report_<часть>.md`
Сначала сводка: сколько OK / FIX / DROP / RISK, средняя интересность, главные системные
проблемы (3–7 пунктов), каких тем/уровней сложности не хватает.

Затем таблица ТОЛЬКО по проблемным вопросам (OK не перечислять):

| id | вердикт | что не так | как исправить (готовый текст) | источник |

Вердикты: **FIX** — исправить (дай готовую новую формулировку/ответ/варианты/факт);
**DROP** — убрать (недостоверно, устарело, скучно и не спасти); **RISK** — острая тема.

В конце — отдельный список `interest` по ВСЕМ вопросам в одну строку на вопрос:
`id | интерес 1–5 | предложенная сложность 1–3` — по нему потом отсортируем банк.

Пиши по-русски. Отчёт пиши по ходу работы (дописывай файл частями), чтобы при обрыве
результат не терялся. В финальном ответе — только краткая сводка (числа и главные проблемы).
